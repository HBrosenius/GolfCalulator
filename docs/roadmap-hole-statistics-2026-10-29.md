# Optional per-hole statistics — 29 October 2026

Individual scorecards now offer a collapsed **Valfri hålstatistik** editor. Select the player and hole, then optionally record putts, fairway hit/left/right/other miss/not applicable, GIR, and penalty strokes. Score-only entry remains the default. Putts and penalties are already included in the gross score; these fields never add strokes or change Stableford points.

The fields are optional annotations on result rows (`stats`). Missing/null fields mean not recorded, distinct from zero putts/penalties and an explicit GIR miss. Fairway is not applicable to par 3. Putts are bounded to 0–10 and penalties to 0–20; recorded putts plus penalties cannot exceed a completed hole's gross score. A pickup has no full gross score and does not enter the summary sample.

The result view and personal course insights show total/average putts, three-putt-or-more holes, fairway/GIR percentages and counts, missed-fairway direction, and penalties. Every metric has its own recorded sample size. Unknown values never become misses or zeros. Course insights use the same player/course/tee/version/date/practice/completion filters as the existing gross-score comparisons. These are self-reported statistics, not strokes gained. Team and match formats do not offer this first version.

Annotations survive local draft saves/recovery, completed-round edits, trash/restore, JSON backups and account snapshots. Live sharing uses optional per-seat data through the existing authenticated score push/retry controller: own-seat annotations remain local-authoritative, other-seat updates are copied and saved into the recoverable draft, and claimed-seat ownership still applies. A score-only patch from an older client preserves annotations on the server. New rounds and reusable group setups start with no old statistics.

Tour submissions preserve optional fields through authoritative score recalculation and local reconciliation. An organizer's change to a hole's score invalidates that hole's statistics to prevent stale/impossible annotations; unchanged holes retain theirs, and the original annotations remain in immutable correction evidence. The correction form explains this before saving. Statistics are optional, do not affect approval or ranking, and are shared with the same audiences as the scorecard when live/tour sharing is enabled. Older app releases may not understand backups containing the new fields; use the current app to restore them.

Deployment stages server validation/persistence before publishing the new editor. Verification covers missing versus zero values, per-metric denominators, malformed fields, par-3 exclusion, score/stat consistency, draft recovery, completed edits, portable backups, filters, live snapshots/permissions/retries, authoritative tour recalculation and correction evidence. Phone layout is checked at 390px width; the service-worker shell includes the new helper and versioned dependent scripts.
